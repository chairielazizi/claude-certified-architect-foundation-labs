# My preferences (all projects) - lead developer's ~/.claude/CLAUDE.md

- Use pnpm, never npm or yarn. If a README says `npm install`, run `pnpm install` instead.
- When you change a public function signature, list every caller you updated.
- Prefer `rg` over `grep` in shell commands.
- Before a large refactor, explain the trade-offs in three bullets or fewer.
